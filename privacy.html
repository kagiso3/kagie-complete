Privacy Notice

Kagie demo mode stores account, application, and document metadata in your browser’s local storage. That means data stays on the device and browser profile you use during testing.

  • Clearing browser storage or using another device resets the demo environment.
  • No live production database is required for the default demo workflow.
  • Do not use real sensitive personal records in demo mode.
  • For production deployment, connect a secure authentication, database, and file storage service.
